This R script performs a complete logistic regression analysis aimed at predicting loan approval outcomes based on several financial variables. It starts by setting the working directory and loading all the necessary libraries for data manipulation, visualization, and statistical modeling. The dataset is then imported from an Excel file, with missing values being properly handled.
The first step is an exploratory data analysis to understand the structure and distribution of the data. It includes the use of summary statistics, histograms, density plots, and boxplots to explore variables like income, credit score, loan amount, and DTI ratio. Bar plots are used for binary variables such as employment status and loan approval. The script also examines correlations between numeric variables using correlation matrices and graphical representations like corrplot and ggpairs.
After the descriptive phase, the script builds a logistic regression model to predict the binary variable "Approval (0/1)" using predictors like credit score, DTI ratio, income, loan amount, and employment status. The dataset is split into a training and a test set to evaluate out-of-sample performance. The initial model is fitted and then refined by removing the employment variable to improve simplicity and potentially model fit.
Model diagnostics follow, including residual analysis, calculation of standard and studentized residuals, and the identification of influential points using Cook’s distance. These points are then removed to re-estimate the model on a cleaned training set. Model assumptions are further checked with the Box-Tidwell test to assess the linearity of the log-odds.
Predictions are generated for the test set, and classification performance is evaluated through accuracy and a confusion matrix. A custom function is included to visually display the confusion matrix along with metrics like accuracy, sensitivity, and specificity. To explore how changing the classification threshold affects performance, the model is also tested using a 0.3 probability cut-off, improving sensitivity at the potential cost of specificity.
Finally, the script uses ROC curves and AUC to assess model discriminative ability. It ends by analyzing how each individual predictor (credit score, loan amount, income, DTI ratio) affects the predicted probability of loan approval, with dedicated plots showing these effects.
Overall, the script is structured to go from raw data to a refined predictive model, through a clear path of exploration, modeling, validation, and interpretation.
